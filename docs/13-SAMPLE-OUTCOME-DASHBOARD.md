# JanSan Sweep — Sample Outcome Dashboard

## What This Is (Read Before Publishing)

This is a **constructed format example built from fictional records.** It is not redacted client data, because JanSan Sweep has no completed client sprints yet.

That distinction is a compliance requirement, not a technicality. Presenting invented records as anonymized real results would be fabricated proof and would violate the brand guardrails in `07-MARKETING-AND-WEBSITE.md` §2.

**Wherever this appears on the website, it must carry this label, visibly, adjacent to the table:**

> **Sample dashboard — illustrative format only.** Business names, dates, and outcomes shown are fictional examples created to demonstrate the report structure. They are not client results. JanSan Sweep publishes real anonymized outcomes only after a completed sprint and with written client permission.

The honest claim this asset makes is *"here is exactly what you will receive"* — a format promise, not a performance claim. That is a strong sell for this buyer, and it stays truthful.
